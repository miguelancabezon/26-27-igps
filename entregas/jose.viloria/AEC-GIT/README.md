# Informe Actividad 1 IGPS

A continuación se describe el proceso realizado para desarrollar la actividad, junto con screenshots como evidencia gráfica 

## 1. Crear la copia del repositorio
Desde el repositorio remoto del profesor le doy click al boton "Fork" para crear un repositorio remoto propio que sea copia del primero, y desde la terminal, con el comando "git clone" clono los archivos a una carpeta personal

## 2. Hacer la estructura de carpetas
Dentro de la carpeta en la que clonamos el repositorio nos dirigimos a las carpetas 26-27-igps/entregas y ddntro cree la carpeta jose.viloria (siguiendo el formato nombre.apellido), y dentro de esta creo otra subcatpeta llamada "AEC-GIT".

## 3. Primer commit y push
Dentro de la carpeta creada anteriormente creo un archivo de texto (README.md) con una única línea inicial y desde la terminal me ubico en la raiz del proyecto (la carpeta 26-27-igps) y añado los cambios al área de staging con "git add .", creo el primer commit junto con su mensaje y mediante "git push" los subo al repositorio

## 4. Una nueva rama 
Desde la raíz del proyecto creo una nueva rama y me ubico en ella mediante el comando "git checkout -b docs/modificaciones", en esta rama hago modificaciones sobre el README (como justo ahora) haciendo commits conforme a los cambios sobre el archivo. Posteriormente subiré los cambios hechos a la rama "docs/modificaciones"
