ACTIVIDAD AEC-GIT

Introducción  En esta actividad estoy practicando los principales flujos de trabajo de Git y GitHub.

Hasta ahora he hecho un fork del repositorio original, he clonado mi repositorio
localmente, he creado la estructura de carpetas solicitada y he hecho el primer
commit con el mensaje "docs: nuevo archivo".

Despues he creado la rama docs/modificaciones, en la que seguiré trabajando
para documentar el proceso mediante diferentes commits.
  

Pasos realizados

1. Entre al repositorio original proporcionado por el profesor y realicé un fork en mi cuenta de GitHub.

2. Cloné mi fork en el ordenador mediante el comando git clone.

3. Dentro del repositorio creé la estructura de carpetas entregas/ruben.cuevas/AEC-GIT.

4. Dentro de AEC-GIT creé el archivo README.txt.

5. Añadí el archivo al área de staging mediante git add y hice el primer commit con el mensaje "docs: nuevo archivo".

6. Subí los cambios a la rama main de mi fork mediante git push origin main.

7. Por último , creé la rama docs/modificaciones para continuar documentando la actividad.
